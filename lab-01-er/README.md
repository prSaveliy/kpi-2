# Опис домену: CRM система для організації турнірів з більярду
Система призначена для автоматизації більярдного спорту: обліку клубної інфраструктури (столи для різних дисциплін більярду), спортсменів та їхніх розрядів, реєстрації учасників, контролю сплати внесків та організації
матчів за столами клубу у реальному часі.

# Заціквлені сторони та їхні задачі
- *Організатор* - створення турнірів (дисципліна, регламент, внески, призові, дедлайн, формат сітки), жеребкування, призначення матчів на вільні столи.
- *Гравець* - профіль зі спортивними даними (розряд/рейтинг), реєстрація на змагання, сплата внеску, слідкування за процесом турніру, відстеження свого столу та фінального місця.
- *Адміністратор клубу* - облік столів, призначення нумерації столів у клубі, типу столу, операційний статус готовності столу до гри.
- *Суддя* - фіксація рахунку зустрічей, перемоги/поразки.
