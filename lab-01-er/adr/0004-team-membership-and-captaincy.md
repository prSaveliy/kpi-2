# Фізичне моделювання складу команди (Team, Team_member) та виділення ролі капітана

## Контекст

У концептуальній ER-моделі зв'язок між `Team` та `Player` було визначено як прямий зв'язок багато-до-багатьох `(M:1..N)` без додаткової сутності. Проте при проектуванні фізичної реляційної схеми БД виникли практичні інженерні вимоги:
1. Фіксація моменту вступу спортсмена до складу команди (`joined_at timestamptz`).
2. Обов'язкова наявність офіційного представника / лідера команди (капітана) для комунікації з оргкомітетом турнірів та внесення заявок.
3. Фізична реалізація реляційної цілісності (RDBMS вимагає сполучну таблицю для відношень M:N зі складеним первинним ключем).

## Розглянуті варіанти

1. **Прапорець `is_captain` у сполучній таблиці членства**:
   Таблиця `team_member (team_id, player_id, joined_at, is_captain)`.  
   **Мінус** — складність забезпечення інваріанта "рівно один активний капітан у команді" на рівні декларативних обмежень SQL без складних умовних індексів або тригерів.

2. **Зовнішній ключ `captain_id` у `Team` + сполучна таблиця `Team_member`**:
   Таблиця `team` містить зовнішній ключ `captain_id int NOT NULL REFERENCES player(player_id)`, а склад команди моделюється окремою таблицею `team_member (team_id PK,FK, player_id PK,FK, joined_at)`.  
   **Мінус** — необхідність транзакційного створення команди (спочатку створення запису `team`, далі додавання записів учасників у `team_member`).

## Наслідки

* **Позитивні:**
  - Суворе забезпечення бізнес-правила: кожна команда має чітко визначеного капітана через прямий зовнішній ключ `captain_id FK -> player`.
  - Можливість зберігання хронології членства спортсменів завдяки бізнес-атрибуту `joined_at` у `team_member`.
  - Повна відповідність 3NF, коректні зовнішні ключі зі складеним первинним ключем `PRIMARY KEY (team_id, player_id)` та підтримка каскадного очищення (`ON DELETE CASCADE`).
* **Негативні:**
  - Потреба узгодження цілісності на рівні бізнес-логіки бекенду: гравець, вказаний як `captain_id`, також має бути доданий до `team_member`.
