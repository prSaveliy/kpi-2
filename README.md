# Моделювання та аналіз вимог до програмного забезпечення (МАВПЗ)

Репозиторій лабораторних робіт та практичних завдань з курсу **«Моделювання та аналіз вимог до ПЗ»**.

---

## Обраний домен: CRM-система для більярдного спорту (Billiard CRM)

Комплексна платформа для автоматизації клубної інфраструктури більярдного спорту (пул, снукер, піраміда тощо), обліку столів, профілів спортсменів, реєстрації учасників, контролю сплати турнірних внесків та організації матчів у реальному часі.

- **Трек виконання:** «З AI» (із збереженням аудиторського ланцюжка промптів, виправлень розбіжностей через специфікацію та архітектурних рішень ADR)

## ⚙️ Інженерні стандарти репозиторію

- **Дотримання Conventional Commits:** Кожен коміт атомарний і має семантичний префікс згідно з [AGENTS.md](./lab-01-er/AGENTS.md):
  - `spec:` — зміни до специфікацій та критеріїв прийняття;
  - `model:` — додавання або регенерація моделей / діаграм;
  - `docs(adr):` — архітектурні рішення у форматі MADR;
  - `audit:` — аудит розбіжностей та документи захисту (`DEFENCE.md`, `AUDIT.md`);
  - `ai:` — промпти та протоколи генерацій ШІ;
  - `render:` — візуальні графічні експорти діаграм;
  - `docs(readme):` — оновлення документації репозиторію.
- **Правило заборони ручного патчу:** Будь-які розбіжності між моделями та вимогами виправляються виключно через оновлення специфікації/критеріїв та повторну генерацію.
